# B13. Доставка атласов шрифтов

**Сравнивали.** Атласы Swift-движка: MTSDF 2048×2048, все четыре канала значимы, два начертания. Сейчас они лежат сырым BGRA по 16 МБ. Варианты:
- сырой RGBA;
- сырой RGBA в gzip, распаковка через `DecompressionStream`;
- PNG без потерь;
- WebP без потерь (`cwebp -lossless -exact`: `-exact` сохраняет RGB под нулевой альфой, а в SDF эти значения значимы).

Картинки декодировались двумя способами: через `createImageBitmap` (`premultiplyAlpha: "none"`, `colorSpaceConversion: "none"`) и через `ImageDecoder` из WebCodecs. Метрика — время на главном потоке от байтов до готовой текстуры, включая завершение работы GPU. Затем текстура считывается обратно и побайтово сверяется с сырым атласом.

Кодировщик: `scripts/encode-atlases.mjs`, бенчмарк: `apps/playground/src/bench/atlas.ts`.

**Окружение.** Mac пользователя (8 логических ядер), Chrome 157 headless (Playwright, системный Chrome), cross-origin isolation включена. 12 итераций после 2 прогревочных.

| формат | КиБ | медиана, мс | p95, мс | байтов отличается |
|---|---|---|---|---|
| сырой RGBA | 16384 | 4.7 | 5.2 | 0 |
| сырой RGBA, gzip | 3236 | 22.4 | 25.5 | 0 |
| (сырой RGBA, brotli на стороне сервера) | 1540 | | | |
| PNG, createImageBitmap | 1168 | 27.0 | 29.6 | 0 |
| PNG, ImageDecoder | 1168 | 24.6 | 25.9 | **3 302 394** |
| **WebP lossless, createImageBitmap** | **816** | **35.7** | **38.7** | **0** |
| WebP lossless, ImageDecoder | 816 | 33.2 | 38.3 | **3 302 394** |

Тонкое начертание даёт те же пропорции (`raw/bench-atlas-2026-11-21-16-37.json`).

**Выводы.**
- `ImageDecoder` не годится. У него нет параметра `premultiplyAlpha`, каналы домножаются на альфу, и пятая часть байтов атласа портится, а с ними и поле расстояний.
- Сырой атлас декодируется быстрее всех, но весит 16 МБ на начертание. Это секунды загрузки на любой реальной сети.
- WebP на 352 КБ меньше PNG и декодируется на 9 мс дольше. Он выигрывает по полному времени (загрузка плюс декодирование) при любой скорости сети ниже примерно 39 МБ/с (310 Мбит/с). Это практически все реальные соединения, а после первой загрузки атлас лежит в HTTP-кэше.

**Решение: WebP без потерь (`-exact`), декодирование через `createImageBitmap` с `premultiplyAlpha: "none"` и `colorSpaceConversion: "none"`, загрузка через `copyExternalImageToTexture`.** Ассеты пакета — `atlas.webp` и `atlas_thin.webp`, по 0,8 МБ вместо 16 МБ.
