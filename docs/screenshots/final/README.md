# Итоговые снимки

Все 15 видов из `Tools/ReadmeFrames/frames.json` эталона на итоговой сборке: 2400×1720 при 2 пикселях на точку, рельеф включён, как рендерит эталон. Снято `node scripts/screenshots.mjs final` на публичном архиве. Виды с моделями (`kremlin`, `bolshoi`, `scene-models-paris`) включают архив моделей явно (`modelArchive=hosted`), потому что в веб-версии он по умолчанию выключен (`docs/STATUS.md`, «После этапа 9»).

Сравнение с `Assets/*.avif` эталона, вид за видом. Камера, палитры, здания, деревья, тени, рельеф, подписи, щиты маршрутов, pins и модели совпадают на всех видах. Общие для всех видов отличия:

- **Значок атрибуции** в правом нижнем углу. Эталон снимает вид без него, а веб-версия рисует его поверх холста (настройки `attribution`).
- **Иконки POI** из набора Maki (CC0) вместо SF Symbols: тот же цвет и положение, другой рисунок значка.

Отличия отдельных видов:

| вид | отличие | причина |
|---|---|---|
| readme-bolshoi | на колоннаде нет тени от квадриги на крыше | тайл модели отбрасывает тень, только когда поднялся, и дальнее окно теней пропускает тайлы внутри своего отверстия (оптимизации этапа 7 и отсечения моделей). На этом виде тень квадриги падает на соседнюю модель и теряется. Не исправлено |
| readme-matterhorn | слабый светлый шов по склону слева | стык тайлов рельефа: сварка краёв (`GroundReliefEdgeWeld`) пишется через `writeTexture`, а не блитом, как в Swift. Причина не подтверждена |
| readme-globe-europe, readme-avatars-globe | дороги и границы на глобусе чуть насыщеннее | код ширины и цвета линий на сфере совпадает со Swift построчно, причина не найдена |
| readme-avatars-shibuya | раскладка pins на 1–2 позиции отличается у края кадра | pins снимаются, как только картинки пришли. Решатель тот же, порядок прихода картинок другой |
| остальные (manhattan, rome, moscow-city, kremlin, paris-region, san-francisco, san-francisco-downtown, berlin-night, zermatt-valley, scene-models-paris) | отличий, кроме общих, не видно | |
