# B12. Дисковый кэш подготовленных тайлов

**Сравнивали.** Запись и чтение 60 тайлов (по 15 штук размером 50 КБ, 200 КБ, 800 КБ и 2 МБ, всего 46 МБ) в воркере:
- **OPFS, упакованный файл:** один файл, один открытый sync handle, индекс смещений;
- **OPFS, файл на тайл:** sync handle или асинхронный `File.arrayBuffer()`;
- **IndexedDB:** `ArrayBuffer` по ключу;
- **Cache API.**

Холодное чтение идёт из нового воркера, тёплое — из того же. Код: `apps/playground/src/bench/storage*.ts`.

**Окружение.** Mac пользователя (8 логических ядер), Chrome 157 headless (Playwright, системный Chrome), cross-origin isolation включена (точность таймера 5 мкс). Фикстуры: `node scripts/fetch-fixtures.mjs`, 131 тайл (Москва и Манхэттен z14–15, Церматт z10–13, Рим z15, Париж z10, глобус z0–5, океан z8). 3 раунда.

| хранилище | запись, медиана | запись p95 | холодное чтение, медиана | p95 | тёплое чтение, медиана | p95 | открытие, мс |
|---|---|---|---|---|---|---|---|
| OPFS, упакованный файл | 0.835 | 3.66 | 0.295 | 0.835 | 0.240 | 0.760 | 0.955 |
| OPFS, файл на тайл (sync) | 1.285 | 3.00 | 0.490 | 0.965 | 0.485 | 0.885 | 0.360 |
| OPFS, файл на тайл (File) | 1.285 | 3.00 | 0.545 | 1.330 | 0.565 | 1.525 | 0.330 |
| **IndexedDB** | **0.450** | 2.48 | **0.265** | 1.340 | **0.260** | 1.235 | 0.230 |
| Cache API | 0.890 | 4.04 | 0.320 | 1.135 | 0.385 | 2.125 | 0.300 |

Все значения в мс на тайл. Сырые данные: `raw/bench-storage-2026-11-21-15-59.json`.

**Решение: IndexedDB.**
- **Чтение:** медианы упакованного OPFS и IndexedDB различаются меньше чем на 10%, это ничья.
- **Запись:** IndexedDB в 1,9 раза быстрее.
- **Простота и доступ из воркеров:** sync handle OPFS эксклюзивен для одного файла. С несколькими воркерами упакованный файл потребовал бы одного владельца кэша и пересылки байтов, а также уплотнения файла при вытеснении. IndexedDB читают и пишут все воркеры одновременно, а вытеснение сводится к удалению ключа.
- **В пользу OPFS:** у упакованного файла короче хвост холодного чтения (p95 0,84 мс против 1,34 мс). Если на этапе 1 холодный старт упрётся в этот хвост, вопрос пересматривается замером на настоящем кэше.
